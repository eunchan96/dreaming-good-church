# 공개 홈페이지와 반응형 탐색

Figma는 참고 자료로 유지하고 실제 구현 화면에서 검토한다는 사용자 결정에 따라 홈과 공통 탐색을 구현했다.

- `/`: PC 환영 영역, 주보 바로가기, 소개·공지·다가오는 일정. 실제 공개 API만 사용한다.
- 768px 이상: 상단 탐색과 2열 콘텐츠. 그 미만: 1열과 주보·공지·일정·교회 안내 하단 탭. 홈은 교회명 또는 홈 링크로 접근한다.
- 관리자 화면에는 공개 홈페이지 탐색을 적용하지 않는다.
- 공개된 교회 소개가 없으면 준비 안내를 표시한다. 대표 사진과 공식 비전 문구는 아직 입력하지 않았다.
- 각 홈 영역은 독립 조회하며 실패하면 이전 내용을 비우고 재시도 버튼을 표시한다. 15초 및 창 포커스 복귀 시 새로 조회한다.
- 본문 16px, 조작 영역 최소 44px, 키보드 포커스와 본문 바로가기, 현재 메뉴 표시, 모바일 안전 영역을 적용했다.
- 홈의 소식 링크는 해당 전체 목록으로 이동한다. 개별 공지 상세 주소는 후속 작업이다.

검증: 타입 검사, ESLint, 프로덕션 빌드, 320/390/768/1440px 탐색·가로 넘침과 조회 실패 복구 Playwright 검사. 공개 API/권한 규칙은 변경하지 않았다.

## 주보 읽기 화면

- PC: 본문 옆 고정 목차. 모바일: 가로로 넘기는 구역 바로가기.
- 목차는 공개 API가 반환한 항목만 사용한다. 이동한 본문 구역에 키보드 포커스가 놓인다.
- 지난 주보 목록은 기본 접힘이며 발행 월을 서버에서 필터링한다. 최신순 20개씩 날짜 커서로 이전·다음 페이지를 탐색하므로 최근 100개 제한이 없다. 월 변경은 첫 페이지로 돌아가며 읽고 있던 본문은 유지한다.
- 같은 주보를 다시 선택하면 본문을 지우지 않는다. 다른 주보를 선택하면 이전 본문·목차를 지운 뒤 새 내용으로 교체한다.
- 조회 실패 시 본문·목차를 제거하고 재시도를 표시한다. 로딩/빈 목록에는 오류 재시도 버튼을 표시하지 않는다.
- 검증: 프로덕션 실행에서 320/390/768/1440px 넘침·목차 포커스·월 필터·선택 유지 검증 1건, 로컬 DB에서 게시/취소·비공개 보호 및 샘플 검증 2건 통과. PC/모바일 스크린샷 확인.

## 날짜별 주소와 공유

`/bulletins/YYYY-MM-DD`는 해당 날짜를 공개 API에서 직접 조회한다. 현재 목록 페이지 밖의 주보도 주소로 조회할 수 있다. 읽기 화면의 고유 주소와 링크 복사 버튼은 현재 표시 중인 주보 날짜를 사용한다. 클립보드 실패 시 주소창 복사를 안내한다.

서버 메타데이터는 익명 권한으로 게시 여부를 재조회하고 날짜·호수와 공통 설명만 제공한다. 본문이나 비공개 항목을 OG/Twitter에 넣지 않는다. 공개 취소·미존재·조회 실패 시 일반 안내와 noindex를 반환한다. 날짜 페이지는 캐시 없이 공개 여부를 확인하는 blocking route(`instant = false`)이다. 공유 서비스가 이미 저장한 외부 미리보기 캐시는 즉시 지울 수 없다.

검증: 실제 로컬 DB에서 게시→날짜 API/직접 접속→OG→클립보드 복사→공개 취소→날짜 API 404/OG 제외/본문 제외를 E2E로 확인했다. 운영 배포 후 실제 메신저의 미리보기 확인은 남아 있다. 대표 공유 이미지와 공식 도메인은 아직 설정하지 않았다.

## 서버에서 지난 주보 찾기

`GET /api/bulletins?month=YYYY-MM&before=YYYY-MM-DD`는 선택한 월과 커서 이전의 게시 주보를 최신순 최대 20개 반환한다. `month`와 `before`는 생략 가능하다. 응답의 `nextCursor`가 null이면 마지막 페이지다. 서버는 21개를 조회해 다음 페이지 존재 여부를 판단한다. 날짜 유일 제약 덕분에 중복 없이 이동하며 중간 게시 취소로 인한 offset 밀림을 피한다. 목록은 방문·15초·창 복귀 시 현재 범위를 다시 조회한다.

목록과 본문 조회는 독립적이다. 목록 실패는 빈 목록과 재시도 안내를 표시하고 본문은 유지한다. 선택한 주보 자체의 조회가 실패하면 본문·목차를 제거한다. 월·페이지 전환 시 이전 목록을 즉시 비우며 취소된 요청은 새 결과를 덮어쓰지 않는다.

검증: 로컬 임시 게시 주보 105개를 전체 순회해 누락·중복이 없음을 확인했다. 월 경계·20개/11개 페이지·초안 제외·이전 페이지·월 변경 초기화·본문 유지·잘못된 월/커서 거절과 기존 게시 취소·샘플·목차 검증 등 E2E 4건 통과. 임시 데이터는 테스트 종료 시 삭제한다.

## 공지·일정·교회 안내

공개 페이지 전용 카드·제목·본문·로딩/빈/오류 스타일을 공통으로 적용한다. 공지와 일정은 한 열로 긴 본문을 읽고, 일정은 한국 시간과 장소를 구분한다. 시간·장소가 비어 있으면 준비 중 안내를 표시한다.

교회 안내는 소개·예배 시간·주소·오시는 길·연락처·이름 순서로 공개된 비어 있지 않은 값만 배치한다. PC는 2열, 모바일은 1열이며 구역 바로가기로 이동한다. 실제 주소나 연락처를 임의로 넣거나 외부 지도 요청을 만들지 않는다.

오류에서만 재시도를 제공하며 재시도 중에는 로딩 안내를 표시한다. 15초 및 창 포커스 복귀 시 조회하고 요청 취소·순서 검사를 유지한다. 실패하면 이전 공개 내용을 비운다.

검증: 320/390/768/1440px 가로 넘침·긴 내용·한국 시간·빈 연락처 제외·바로가기 키보드 포커스·실패 재시도와 실제 공개/비공개 샘플 E2E 2건 통과. PC 교회 안내·모바일 일정 스크린샷 확인.

## 일정 달력

일정은 기본 목록에서 달력으로 전환할 수 있다. 한국 시간의 이번 달·이전/다음 달·날짜 선택·이 달 전체 보기를 지원한다. 여러 날 일정은 시작일부터 종료 직전 날짜까지 표시하며 자정 종료는 다음 날에 중복 표시하지 않는다. 모바일에서는 44px 이상 날짜 버튼을 유지하고 달력 영역만 가로 스크롤한다.

달력 월 변경 시 서버의 month=YYYY-MM 조회로 해당 월과 겹치는 공개 일정만 가져온다. 공개 권한은 기존 익명 RLS를 사용한다. 월별 최대 100개이며 초과 시 잘림 안내를 표시한다. 서버 전체 기록 페이지 이동은 후속 개선이다. 목록 복귀 시 월 필터를 해제한다.

검증: 한국 시간 날짜 경계·다일 일정·날짜 선택·월 이동·목록 복귀·320px 넘침 및 공개/비공개 샘플 E2E 2건 통과. 로컬 월 조회에서 공개 샘플 2개 확인.

후속: 실제 대표 사진·소개·새가족 안내 및 지도 연결. 인쇄 지면과 HWP 가져오기는 별도 WBS 범위다.
