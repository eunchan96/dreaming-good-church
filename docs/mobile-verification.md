# 모바일·접근성·PWA 검수

실제 기기는 사용자가 선택한 안드로이드다. PC Edge의 모바일 크기 시뮬레이션과 실제 Chrome/OS 동작을 구분한다. iPhone은 사용할 기기가 확인되지 않아 미검증으로 남긴다.

## 자동 확인

- 홈·주보·교회 안내·공지·일정5개 화면을390/1280px에서 axe-core WCAG2 A/AA·2.1/2.2 AA 규칙으로 검사했다. 자동으로 감지 가능한 위반0건이며 수동 접근성 검수를 대체하지 않는다.
- 본문 바로가기의 키보드 초점 이동을 수정했다. 본문을 탭 순서에 반복 추가하지 않고 Tab→Enter로 이동하며 초점을 표시한다.
-320px 하단 메뉴의44px 이상 터치 영역, 키보드 메뉴 이동,320/390/844px에서 글자200% 확대 시 가로 넘침 없음, 클립보드 거절 시 고유 주소 안내를 확인했다.
- 서비스 워커의 관리자/API/이미지/PDF 캐시 제외, 명시적 공개 저장만 허용,24시간 만료/삭제, 갱신 실패 시 이전 저장본 제거를 확인했다. HTTPS가 아닌 모바일 HTTP에서는 저장 버튼이 비활성화되고 이유를 안내한다.
- 전체 브라우저23건·타입·ESLint·프로덕션 빌드 통과. 에뮬레이션/모의 설치 이벤트 결과이며 실제 안드로이드 설치 완료가 아니다.

## 접속 환경

같은 Wi-Fi의 휴대폰에서 `http://<PC의 Wi-Fi IPv4 주소>:3001`로 로컬 샘플을 볼 수 있다. PC에서는 `npm run dev:local`이 실행되어 있어야 한다. 가상VMware/WSL 주소 대신 실제 Wi-Fi 주소를 사용한다. 접속이 안 되면 같은망/게스트망 분리·PC 방화벽을 확인한다. 방화벽 전체 해제나 인터넷 포트 개방은 하지 않는다.

로컬 HTTP는 화면 확인용이다. 홈 화면 설치·서비스 워커·오프라인 검수는 신뢰된HTTPS 주소에서 진행한다. 휴대폰의 localhost는 휴대폰 자신이므로 PC의 localhost 주소를 복사하지 않는다. Vercel 미리보기가 로그인 보호 중이면 먼저 해당 Vercel 계정으로 접속한다. Vercel 인증과 교회 관리자 로그인은 별개다.

## 안드로이드 실제 기기 체크리스트

각 항목에 결과·기종/Android/Chrome 버전·재현 순서·스크린샷을 기록한다. 아래 항목은 아직 실기기 미검증이다.

- [ ] HTTPS 주소에서 홈·주보·공지·일정·교회 안내를 열고 세로/가로 전환, 글자 크게 설정, 긴 표·사진, 하단 탭의 잘림/가려짐 확인.
- [ ] Android TalkBack으로 메뉴·제목·버튼·사진 설명의 읽기 순서와 초점 이동 확인. 키보드가 있으면 Tab/Shift+Tab·본문 바로가기 확인.
- [ ] 주보 고유 주소를 복사하여 다른 Chrome 탭에서 같은 날짜가 열리는지 확인. 클립보드 불가 시 고유 주소에서 주소창 공유 기능 사용.
- [ ] Chrome 메뉴의 앱 설치/홈 화면에 추가 실행. 임시 아이콘·이름 확인 후 홈 화면에서 독립 창으로 열기. 설치 취소 후 사이트 재사용도 확인.
- [ ] ‘공개 주보·안내 저장’ 후 저장 시각 확인→비행기 모드→공개 주보 경로 다시 열기→저장본 표시 확인. 이미지/공지/일정/관리자는 저장 대상이 아님을 확인.
- [ ] 저장본 삭제 후 새로 열면 내용이 남지 않는지 확인. 온라인으로 복귀해 현재 게시 내용으로 돌아오는지 확인. 저장 후 게시 취소된 내용은 오프라인에 최대24시간 남을 수 있음.
- [ ] 공개PDF 내려받기·한글/사진 읽기 확인. 비공개 항목 제외, 게시 취소 후 새 다운로드 차단 확인. 이미 다운로드한 파일은 회수되지 않음.
- [ ] 관리자 계정으로 편집 후 앱 전환/화면 잠금·복귀, 세션 종료 시 입력 보존/재로그인 확인. 실제 운영 자료 대신 사용자가 허용한 검수 초안 사용.
- [ ] 실제 이동통신/느린망에서 첫 진입·주보 열기·PDF 다운로드의 체감 지연/중복 클릭/오류 복구 확인. 로컬 개발 서버 시간으로 실제 성능을 판정하지 않음.

공식 교회 아이콘 교체, 실물 프린터 양면/여백·접지, iPhone 검수는 별도 대기다. WBS39는 실제 기기 결과가 오기 전 진행 중으로 유지한다.

## 실제 기기 진행 결과 · 2026-11-13

사용자는 안드로이드 정상 접속·설치 완료를 확인했다. 이어 공개 저장 시 ‘저장하지 못했습니다. 연결을 확인하고 다시 시도해 주세요.’를 보고해 오프라인 항목은 통과하지 않았다. Vercel 접근 쿠키를 유지하도록 수정하고 보호된 출처를 모의한 실제 서비스워커 회귀 테스트를 추가했다. 앱 Authorization 헤더가 전송되지 않는 것과 저장한 공개 안내의 오프라인 표시까지 확인했다. 관련 브라우저6건 통과, 실제 안드로이드 재확인은 배포 후 진행한다.
