# 홈 화면 설치

매니페스트 `/manifest.webmanifest`는 꿈꾸는좋은교회/좋은교회 이름, 루트 시작 주소, standalone 표시 모드, 테마 색과 192/512px 아이콘을 제공한다. 아이폰용 180px 아이콘과 브라우저 favicon도 포함한다.

현재 아이콘은 임시 십자가·교회 그림이다. 공식 아이콘은 사용자에게 파일을 받은 뒤 교체한다. 원본 `public/icons/church-source.svg`와 생성 스크립트 `scripts/generate-app-icons.mjs`를 사용하며 `npm run icons:generate`로 크기별 PNG와 favicon을 재생성한다. 공식 원본 형식이 다르면 스크립트의 입력 경로도 바꾼다. 설치된 기존 앱의 아이콘 갱신 시점은 기기·브라우저에 따라 다르다.

공개 페이지 하단의 설치 안내를 열면 iOS Safari 공유 메뉴, Android Chrome, PC Chrome/Edge 방법을 볼 수 있다. `beforeinstallprompt`가 실제 제공될 때만 직접 설치 버튼을 표시한다. 취소·오류 후 안내로 복귀하고 `appinstalled`/standalone으로 실행 중임을 감지한다. 알림 권한을 요청하지 않는다.

설치는 HTTPS 또는 localhost 환경에서 브라우저의 지원·설치 조건에 따른다. 로컬 네트워크의 HTTP IP 주소에서는 설치 메뉴가 보이지 않을 수 있다. 실제 iOS/Android/PC 홈 화면 설치는 외부 HTTPS 배포 후 확인한다.

## 선택적 오프라인 저장

공개 페이지에서 서비스 워커 `/sw.js`를 등록한다. 설치 안내 안의 ‘공개 주보·안내 저장’을 누를 때만 워커가 credentials same-origin으로 공개 API를 다시 조회한다. 같은 사이트의 Vercel 접근 인증 쿠키를 유지하며 앱 Authorization 헤더는 보내지 않는다. 공개 API는 요청자의 쿠키를 Supabase에 전달하지 않고 익명 클라이언트로 조회한다. 최신 게시 주보 한 개의 글·표(이미지 제외)와 공개 교회 안내를 저장한다. 실패하면 기존 저장본도 제거한다.

Cache Storage `church-offline-v1`에는 독립 HTML `/offline.html`과 `/offline-data.json` 두 항목만 저장한다. Next 페이지 HTML/RSC·JS·API 응답·인증·관리자·파일·이미지·공지·일정은 저장하지 않는다. 일반 API 요청은 오프라인에서도 캐시로 대체하지 않는다. 공개 페이지의 전체 이동이 네트워크 실패하면 독립 오프라인 화면으로 안내한다. 관리자 이동에는 이 대체 화면도 적용하지 않는다.

저장본은 최대24시간이며 사용자가 지울 수 있다. 저장 시점을 표시하고, 요청 날짜와 다른 ‘저장 당시 최신 주보’임을 알린다. 저장 이후 비공개 전환/게시 취소는 오프라인 기기에 즉시 반영할 수 없다. 온라인에서는 정상 API를 조회하며 저장본은 명시적 오프라인 화면에서만 본다. 공용 기기는 사용 후 삭제하도록 안내한다.

검증: 실제 브라우저 서비스 워커에서 저장→네트워크 차단→공개 경로 이동 대체/본문 표시, 비공개 샘플 제외, 관리자 이동 실패·API 실패(캐시로 대체 안 함), Cache Storage 허용2항목만 저장,24시간 만료·삭제 E2E 통과. 개발 서버 반복 새로고침으로 첫 실행이 실패해 로컬 테스트 서버 재시작 후 통과했다. 실제 HTTPS 기기 설치·오프라인 확인은 배포 후 진행한다.

검증: 매니페스트 이름/시작 주소/standalone과 실제 PNG 크기, 설치 이벤트/취소/완료 상태 및 320px 넘침 E2E2건. 네이티브 설치 대화상자는 브라우저 이벤트를 모의해 상태 처리를 검증했으며 실제 OS 설치를 완료했다는 뜻은 아니다.

## 보호된 미리보기 저장 실패 수정

2026-11-13 사용자 실기기 보고: 안드로이드 접속·설치는 성공했으나 저장 시 일반 연결 오류가 표시됐다. 기존 credentials omit이 Vercel 접근 쿠키를 제외해 API가 인증 화면으로 전환되는 조건을 확인했다. 쿠키가 있어야 API를 허용하는 로컬 서버와 실제 서비스워커를 연결한 회귀 테스트에서 수정 전 실패·수정 후 저장 및 오프라인 표시 성공을 검증했다. 같은 출처 쿠키만 유지하며 Vercel 보호를 해제하지 않는다.

설치 검수는 고정 브랜치 주소 `https://dreaming-good-church-git-codex-bulle-a36b08-eunchan96s-projects.vercel.app`를 사용한다. 개별 배포 주소는 불변이므로 새 배포 후에도 기존 설치가 계속 옛 코드를 열 수 있다. 기존 개별 주소로 설치했다면 Chrome에서 고정 주소를 열어 다시 설치하고, 이후에도 같은 고정 주소를 사용한다. 저장본은 출처별로 분리되므로 새 주소에서 다시 저장해야 한다. 실제 안드로이드 저장 재확인은 사용자 결과 대기다.
