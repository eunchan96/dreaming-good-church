# 공개 홈페이지 UI 1차 구조 개선 · 2026-11-13

사용자 요청으로 관리자보다 공개 홈페이지를 먼저 개선했다. [LDI](https://www.ldi.kr/)의 넓은 환영 영역·간결한 그룹 메뉴·섹션별 흐름·정보를 모은 푸터를 참고했다. 타 사이트의 사진/브랜드/문구를 복제하지 않았다. 광성교회 레퍼런스는403으로 열리지 않아 이번 시각 검토 근거로 사용하지 않았다.

## 색·글꼴·브랜드

- 추천/구현: 아이보리 바탕+짙은 갈색 본문, 로고에서 가져온 노란 포인트. 노란색을 작은 본문 색으로 쓰지 않고 주요 장식/영역에 사용한다. 보조 글자는 대비 검증 후 진하게 보정했다.
- 공개 화면은 Noto Sans KR, 큰 제목은 Noto Serif KR로 구분한다. next/font로 자체 제공하며 관리자 본문 폰트는 바꾸지 않았다.
- 캡처 로고는 확대하지 않고 C형 노랑/갈색 십자가/붉은 하트를 참고한 임시 SVG로 작성했다. 원본 공식 로고의 정확한 복원/최종 확정은 아니다. 파비콘·설치 아이콘도 같은 임시 원본으로 생성한다.
- 제공 배너는 원본 비율/크기를 무리하게 확대하지 않고 푸터에 사용한다. 히어로는 실제 교회 사진처럼 보이는 타 교회 사진 대신 추상적인 창/햇빛 장식을 사용했다. 실제 고해상도 교회 사진이 확보되면 교체를 검토한다.

## 메뉴와 홈 추천 구현

고정 상단바 순서는 교회 소개→예배→소식이다. 교회 소개: 인사말/오시는 길/예배시간 안내/온라인 헌금, 예배: 주일/주일오후/금요/새벽, 소식: 교회 소식/주보/일정으로 구성했다. PC는 그룹 메뉴, 모바일은 접는 전체 메뉴다. 키보드 Escape/메뉴 밖 클릭/선택 후 닫힘과 현재 메뉴 표시를 제공한다. 모바일 고정 하단 메뉴는 전체 메뉴로 통합했다.

홈은 환영 메시지→최근 주일 말씀→처음 방문 안내→주보/교회 소개/공지/일정→예배 초대 순서다. 실제 등록 내용이 없으면 빈 상태를 표시하며 가상 소식·행사를 운영 DB에 넣지 않는다. 화살표/시계/지도/재생/메뉴는 SVG 아이콘, 모션은 짧은 등장/호버 수준이며 모션 줄이기를 따른다.

푸터에는 교회명/주소/연락처·메뉴 바로가기·YouTube·제공 배너·저작권·맨 위로·작은 로그인 링크를 둔다. 설치/오프라인 안내는 푸터 하단의 닫힌 펼침 영역으로 옮겨 기능을 유지한다. 실제 개인정보/사진 게시 정책 문서가 확정되기 전 가짜 정책/빈 링크는 추가하지 않았다.

## 예배 영상과 공개 정보

공식 채널 UCSkvK9jOZFIT84hiS0B5Rzg의 공개 목록을 확인했다. 주일 기본 화면은 최신 주일 말씀 임베드, 아래 예배시간 표다. 다른 예배 탭은 실제 해당 재생목록으로 연결하고 목록의 첫 영상을 최신이라고 부르지 않는다. 현재 전체예배/금요/새벽 재생목록은 과거 영상부터 시작하는 목록임을 확인했다.

주일 최신 선택은 고정된 공식 채널의 최신순 uploads 공개 메타데이터에서 찬양/오후/금요/새벽/짧은 말씀을 제외하고 주일/설교·본문형 제목을 찾는다. URL은 고정, JSON만 파싱(스크립트 실행 없음), 채널ID/영상ID/길이·3MB/6초 제한을 검증한다. 결과는10분 재검증 캐시이며 실패 시2026-11-13에 확인한 OSfMkv-YWJQ 영상과 ‘최근 확인한 주일 말씀’ 문구를 사용한다. 영상 서비스 실패가 홈페이지를 막지 않게 했다.

이는 YouTube Data API/채널 관리자가 지정한 서비스 유형에 따른 확정 분류가 아닌 현재 공개 uploads 제목 규칙이다. 채널 제목/마크업 변경·새 특수 영상으로 분류가 달라질 수 있으며 공식 API/관리자 선택 연동은 후속 검토다. 외부 플레이어 자체의 접근성·재생 정책도 사이트에서 제어할 수 없다. YouTube에서 바로 여는 대체 링크를 둔다.

주소는 제공 배너, 연락처/일반 예배 시간은 기존 주보의 안내를 참고했다. 오후예배의 정확한 시간은 미정으로 문의 안내를 둔다. 온라인 헌금 계좌는 이전 전사의 오류를 고려해 공개하지 않고 확인/문의 상태로 구성했다. 기존 관리자 교회 정보의 공개 본문·주소/전화/추가 예배 안내는 새 소개 화면에도 읽어 반영한다. 푸터/기본 시간표의 정적 안내를 관리자 설정으로 통합하는 작업은 별도다.

## 범위와 검증

관리자 입력/인쇄/PDF/게시·RLS·DB 자료/키/Auth 설정은 변경하지 않았다. 공개 화면/최신 영상 조회 API·브랜드 자산 및 검증 파일을 변경했다. CHURCH_BUILD_CHECK=1은 별도 .next-build-check 빌드 경로로 개발 서버의 출력 경로와 분리한다.

단위 테스트는 최신순 선택/다른 서비스와 찬양 제외/다른 채널·잘못된 메타데이터 실패 닫힘을 검증한다. 브라우저는 그룹 메뉴·모바일·키보드·고정 상단·footer 유틸리티·예배탭·기존 공개 조회 오류 복구·설치 안내를 검증한다. 자체 UI 접근성은 외부 YouTube iframe 내부를 제외해 검사하며 우리 iframe의 제목·목적지는 별도로 검사한다. 원본 사진 전사 정확도나 실물 인쇄품질 검증을 이번 UI 검증에 포함하지 않는다.

원본 로고·최종 색/문구·계좌 확인·오후예배 시간·실제 교회 사진·영상 선택의 확정 분류/관리자 연동은 계속 조정할 항목이다. 이번은 큰 틀의 첫 구현이며 WBS25 전체를 완료 처리하지 않는다.
