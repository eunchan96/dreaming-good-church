# 교회 안내 설정과 로그인 복구

WBS25.16 / PR12. 로컬 구현·검증 단계이며 원격 스키마와 Preview 연결은 새 백업/Drive 검증 뒤 진행한다. 실제 운영 안내값은 임의로 저장하지 않는다.

## 관리자 사용

`/admin/church` 상단 관리 메뉴와 왼쪽 빠른 목차를 사용한다. 기존 인사말·주소·연락처·웹 공개 설정은 항목별로 유지한다.

- 예배시간: 주일·오후·금요·새벽·학생·월삭 6종의 요일/주기와 시각. 입력은24시간제이며 공개 화면은 오전/오후/저녁으로 표시한다. 주보의 이번 주 말씀은 기존대로 예배 화면의 해당 시간 아래에 표시한다.
- 온라인 헌금계좌: 일반/건축 계좌의 은행·번호·예금주. 저장 전 두 계좌 전체를 확인한다. 계좌 진위를 자동 확인하는 기능은 없다.
- 지도·방문안내: 위도·경도·확대 단계·주변 위치·교통/도보 설명. 지도 미리보기를 제공한다. 주소는 기존 주소 항목에서 따로 저장하므로 좌표와 일치하는지 확인한다.

묶음마다 저장·다시 불러오기가 있다. 저장은 선택한 묶음만 반영하며 다른 미저장 내용은 보존한다. 낡은 버전의 저장은 거절하고 입력을 유지한다. 다시 불러오기는 해당 묶음의 미저장 입력 폐기를 확인한 뒤 실행한다. 새 구조화 설정은 저장 즉시 공개이므로 도움말과 저장 확인에서 안내한다.

별도 설정이 없으면 사용자와 확인한 현재 기본값을 표시한다. 오후13:00, 학생09:30, 월삭05:25, 일반 농협301-0223-0182-71/건축301-0220-0484-81(좋은교회), 확인된 지도 좌표와 선아빌딩 방문 안내를 유지한다. 마이그레이션은 안내값을 자동 저장하지 않는다.

## 공개 화면

`GET /api/church-settings`는 세 묶음의 공개 값만 반환하고 revision은 제외한다. no-store,15초/탭 복귀 갱신. 예배 페이지와 교회 소개의 시간표가 같은 설정을 사용한다. 학생/월삭은 교회 소개 시간표에 추가된다. 주소/전화는 기존 웹 공개 여부를 존중하며 푸터에도 동일하게 반영한다.

헌금계좌는 정상 조회가 완료된 뒤에만 표시한다. 조회 실패 시 이전 계좌나 기본 계좌를 대신 노출하지 않고 재시도를 제공한다. 지도/시간표 조회 실패도 상태와 재시도를 제공한다. 지정 좌표를 사용하므로 주소 검색이 엉뚱한 위치를 확대하는 동작을 피한다.

## 로그인 복구

홈·예배 영상·교회 정보·공지 관리의 세션 안내를 같은 카드로 통합했다. ‘관리자 로그인’은 새 탭, ‘로그인 다시 확인’은 현재 탭의 권한 재확인이다. 확인 중 버튼을 비활성화한다.

미저장 내용이 있으면 현재 탭에 보관 중임을 알린다. 같은 계정 재로그인은 입력을 유지하고 다른 계정 전환은 이전 입력을 초기화한다. 로그인 전에는 편집 내용을 숨긴다. 새로고침/탭 닫기를 견디는 영구 저장을 의미하지 않는다.

## 데이터·검증

`church_page_settings`: key/payload/revision, 세 묶음만 허용. JSON 형식·시간·계좌 문자·좌표/확대 단계·글자 길이를 DB와 클라이언트에서 검증한다. editor RLS와 security invoker RPC에서 권한을 확인하고 revision으로 동시 저장을 차단한다. 익명은 key/payload만 읽고 쓰기·revision 조회는 불가하다. 일반 로그인 사용자도 편집 권한 없이는 읽기/저장이 불가하다.

암호화 백업의 테이블 목록과 SQL 복구·RLS 수용 검사에 새 테이블을 포함했다. 새 테이블이 없는 이전 백업도 지원한다.

로컬 검증: 단위35건, 새 재로그인/설정/계좌 오류 복구3건 및 기존 교회 정보·주보 이미지/공개 화면6건 통과. 묶음별 저장·취소·충돌, DB 입력 거절·익명 권한, 같은/다른 계정 복구, 주소 비공개·푸터 반영,1440/390/320px 넘침/접근성 검사, lint·타입·격리 빌드·로컬 security/performance WARN 검사 통과. 운영 자료로 실행한 검증이 아니다.
