# 관리자 인쇄 미리보기

주보 편집의 ‘인쇄 미리보기’는 로그인한 운영자의 현재 주보 전체 항목을 표시한다. 웹 비공개·초안 항목도 포함하며 공개용 PDF가 아니다. 현재 입력을 사용하므로 미저장 변경이 있으면 화면에 알린다. 미리보기를 열거나 인쇄해도 게시/공개 여부가 바뀌지 않는다.

별도 공개 URL·Storage 파일·공유 서버 캐시를 만들지 않는다. 기존 관리자 세션의 화면 안에서 portal로 표시하며 세션 만료로 편집 화면이 잠기면 함께 제거된다. 이미지는 기존 인증 API의 blob URL을 사용한다. 앱의 인쇄 버튼은 이미지 수·decode·폰트 준비를 확인한 후 window.print를 호출한다. OS 인쇄 메뉴의 직접 단축키는 이 준비 검사를 우회할 수 있다.

브라우저 인쇄 창에서 프린터 또는 PDF 저장을 선택한다. 운영자 PC에서 직접 생성되는 PDF이므로 웹 비공개 내용을 포함한다. 공개용 PDF 자동 생성·다운로드 기능은 아직 없다.

사용자가 확정한 **A4 가로 한 장 반접지 → A5 4면**을 적용했다. 두 인쇄 쪽을 겉면4·1/안쪽2·3 순서로 배치한다. A4 전체 크기 안쪽8mm, 면 안쪽6mm 여백이며 브라우저는 A4가로·배율100%·여백없음·머리글/바닥글끔으로 설정한다. 프린터 양면 뒤집기 방향은 기기별 시험 출력이 필요하다.

이미지는1면, 예배/설교 블록은2면, 제목에 묵상/기도문/메모/토라/목장이 있으면3면, 나머지는4면으로 기본 배치한다. 종류/제목 기반 제안이며 원본 HWP를 분석한 결과가 아니다. 항목별 면 선택으로 수정하며 각 면 안에서는 주보 순서를 유지한다.

면 선택은 항목의 print_page(1~4, NULL=자동)로 저장한다. 기존 주보는 NULL을 유지해 자동 배치를 사용한다. UI의 printPage 변경은 다른 편집과 같은 dirty/revision/자동저장 흐름이며 첫 저장은 수동이다. 재열기·초안/게시 주보 복사에 면 배치를 보존하고, 게시된 주보의 선택창은 읽기 전용이다. 수정하려면 게시를 취소한다. 다른 탭과의 충돌은 기존 revision 검사로 거절한다.

마이그레이션 20261112131506_bulletin_print_page를 로컬 및 지정 운영 Supabase에 적용했다. JSON 면 값은 1~4 정수만 허용하고 잘못된 값은 트랜잭션을 롤백한다. 익명 역할에 새 열 조회 권한을 부여하지 않으며 공개 API/공유 메타데이터/오프라인 저장에는 인쇄 면을 추가하지 않는다.

화면과 인쇄의 물리 크기·글자·표 높이를 동일하게 유지한다. ResizeObserver와 폰트 준비 후 면의 세로/가로 넘침을 검사하고 인쇄 버튼에서도 재검사한다. 넘친 상태는 본문 인쇄를 막고 브라우저 직접 인쇄에도 안내문만 출력한다. 내용을 자동 삭제·축소·다음 면 이동하지 않는다. 사용자가 면 이동 또는 내용 수정으로 해결한다. 조작 UI·공개 여부 문구는 인쇄에서 제외한다. 실제 프린터의 여백/긴 표/실물 접지 검수와 원본의 세부 시각 디자인은 후속이다.

키보드 Tab 포커스를 미리보기 안에 유지하고 Escape/닫기로 편집 화면에 복귀한다. 모바일 화면 크기에 맞춰 줄바꿈한다.

검증: 비공개 항목의 웹 제외/인쇄 포함,4·1/2·3 DOM순서·면 이동, print 미디어 편집화면/버튼 제외, 모바일 가로 넘침·닫기, 긴 본문 넘침 차단/안내문 대체 E2E. 이미지 로드/인쇄 호출은 window.print 모의로 검증하고, 브라우저 PDF의 물리 쪽 수를 확인한다. 실제 프린터 실물 검수는 별도다.

저장 연결 검증: 로컬 DB14건·단위13건, 브라우저 저장/복사/재열기 및 공개 제외2개 시나리오, 생성 타입 일치·타입·ESLint·빌드 통과. 다음은 공개용 PDF 출력으로 비공개 항목 제외와 게시 취소 접근을 분리해 검증한다.
