# 관리자 인쇄 미리보기

주보 편집의 ‘인쇄 미리보기’는 로그인한 운영자의 현재 주보 전체 항목을 표시한다. 웹 비공개·초안 항목도 포함하며 공개용 PDF가 아니다. 현재 입력을 사용하므로 미저장 변경이 있으면 화면에 알린다. 미리보기를 열거나 인쇄해도 게시/공개 여부가 바뀌지 않는다.

별도 공개 URL·Storage 파일·공유 서버 캐시를 만들지 않는다. 기존 관리자 세션의 화면 안에서 portal로 표시하며 세션 만료로 편집 화면이 잠기면 함께 제거된다. 이미지는 기존 인증 API의 blob URL을 사용한다. 앱의 인쇄 버튼은 이미지 수·decode·폰트 준비를 확인한 후 window.print를 호출한다. OS 인쇄 메뉴의 직접 단축키는 이 준비 검사를 우회할 수 있다.

브라우저 인쇄 창에서 프린터 또는 PDF 저장을 선택한다. 운영자 PC에서 직접 생성되는 PDF이므로 웹 비공개 내용을 포함한다. 공개용 PDF 자동 생성·다운로드 기능은 아직 없다.

첫 구현은 A4 세로 연속형·14mm 여백이다. 화면 조작·편집 UI·공개 여부 표시 문구를 인쇄에서 제외하고 전체 항목만 출력한다. 사용자가 실제 규격을 **A4 가로 한 장 반접지 → A5 4면**으로 확정했다. 다음 구현은 겉면4·1/안쪽2·3 배치다. 해당 4면 배치·여백·긴 표와 페이지 넘침·실물 출력 검수는 아직 후속이다. 사용자 사진의 지면을 완성한 것으로 간주하지 않는다.

키보드 Tab 포커스를 미리보기 안에 유지하고 Escape/닫기로 편집 화면에 복귀한다. 모바일 화면 크기에 맞춰 줄바꿈한다.

검증: 비공개 항목의 웹 미리보기 제외/인쇄 포함, print 미디어에서 편집 화면·버튼 제외, 모바일 가로 넘침·닫기, 기존 게시/취소·공개 권한 E2E. 이미지 로드/인쇄 호출은 실제 OS 인쇄 대신 window.print를 모의해 검증한다. 실제 프린터 출력과 PDF 지면 검수는 별도다.
