## 2026-11-14 화면별 디테일 개선 계속

관리자 UI 전체는 진행 중이다. 이번 사용자 피드백으로 영상 목록과 등록/수정을 독립된 본문 화면으로 나누고, 왼쪽 빠른 이동에서는 현재 화면의 목차만 펼친다. 공지·일정에도 목록/등록·수정 분리와 임시 저장/저장 이름을 적용했다. 주보의 자동저장·검토·게시 흐름에는 일괄 적용하지 않는다.

등록은 종류/날짜/링크/제목으로 라벨을 줄였다. 유효한 링크를 입력하면 인증된 `/api/worship/title`에서 YouTube oEmbed 제목을 읽고, 사용자 수동 입력·바뀐 링크·닫힌 화면에는 늦은 응답을 적용하지 않는다. 실패하면 직접 입력할 수 있다. 미리보기/대표 설정의 제목·설명은 제거했다. 임시 저장은 비공개, 저장은 공개이며 공개 상태에서 임시 저장하면 공개 취소를 확인한다. 기존 보관은 공개 목록에서 내리는 기능이라 기존 공개 영상 편집에만 명확한 이름으로 남긴다.

# 관리자 UI · 로그인과 공통 편집 화면

## 범위와 방향

사용자 요청으로 영상 등록 기능에 앞서 로그인부터 관리자 UI를 정돈한다. 홈페이지와 같은 아이보리 바탕·짙은 갈색 글자·노란 포인트·Noto Sans KR/큰 로그인 제목 Noto Serif KR·임시 교회 로고를 사용한다. 공개 홈페이지와 관리 공간의 목적은 구분하며 같은 브랜드 안에서 사용한다.

- 로그인: PC 환영 영역+로그인 카드, 모바일 한 열. 초대받은 운영자 안내, 입력 바로 옆 비밀번호 보기/숨기기, 실패 문구를 폼 안에 배치. 실제 재설정 메일을 자동으로 보내거나 일반 가입을 추가하지 않는다.
- 계정 설정: 같은 브랜드와 카드/입력 UI, 기존 token_hash 확인·초대/재설정·12자 비밀번호·재입력/사용자·멤버십 재검증을 유지한다. 토큰을 표시하거나 자동으로 소비하지 않는다.
- 공통 상단: 공개 홈페이지처럼 브랜드·주보/공지·일정/교회정보 관리 전환·공개 화면 확인1개·로그아웃을 배치한다. 왼쪽은 페이지 내 소제목 목차다. 주보는 보관함/선택한 주보 각 항목/게시/복사, 교회정보는 각 정보/이미지, 공지는 목록/편집으로 빠르게 이동하고 본문에 포커스를 옮긴다. 인가되지 않은 상태에는 관리 메뉴/목차를 숨긴다. UI 숨김은 접근 제어를 대신하지 않으며 기존 Auth/멤버십/RLS 검증을 유지한다.
- 모바일: 상단 버튼 아래에 관리 전환 메뉴가 열리고, 페이지 목차는 상단 아래 가로 탐색으로 바뀐다. 스크롤 후에도 메뉴 접근, 선택 후 닫힘/Escape 닫기·버튼 포커스 복귀, 본문·목차의 가로 넘침 분리를 검증한다.
- 편집 화면: 따뜻한 카드·낮은 모서리 곡률·일관된 입력/버튼·상태 배지·갈색 주요 버튼. 주보 보관함·현재 선택·저장/게시/미리보기, 공지·일정 목록/폼, 교회정보·이미지 폼에 적용한다. 빈 상태 메시지가 불필요한 높이를 차지하지 않도록 한다.
- 교회정보: 중첩 박스/반복 링크를 없애고 얇은 구분선·작은 항목별 저장/공개 체크·개별 다시 불러오기로 구성한다. 저장값은 편집란에 표시하고 수정 중에는 원래 저장값을 펼쳐 볼 수 있다. 저장값이 비면 현재 기본 안내를 구분해 보여주고 명시적으로 불러와 저장하게 한다. 화면 방문만으로 기본 안내를 DB에 쓰지 않는다. 긴 설명은 i 도움말로, 저장/실패/미저장 상태와 필요한 경고는 바로 표시한다. 공개 화면 확인은 상단 한 곳이며 미저장 내용을 미리보기하는 기능이 아니다.

도움말은 native details/summary, 화면 폭 안으로 위치 보정한 떠 있는 패널, 바깥 클릭/Escape 닫기·포커스 복귀를 제공한다. 주보 항목은 큰 카드 반복 대신 구분선, 목록 보관함은 본문 상단의 얕은 영역으로 정리해 왼쪽을 목차 용도로 유지한다.

## 교회정보 항목별 저장

기존 church_info의 editor RLS·SELECT/UPDATE 권한을 사용한다. 서버 키/새 RPC·마이그레이션을 추가하지 않는다. saveChurchField는 선택한 key와 원래 revision을 모두 조건으로 body/web_visible·revision+1만 단일행 UPDATE하고 반환값을 확인한다. 반환 행이 없으면 충돌로 거절하고 입력을 보존한다.

저장 성공 시 그 항목의 편집값/원본/버전만 갱신한다. 다른 미저장 항목의 본문·공개 설정·버전은 바꾸거나 저장하지 않는다. 다시 불러오기도 항목별이며 미저장 내용이 있으면 확인한다. 주보/이미지의 기존 저장·동의·게시 규칙은 그대로다. 교회 이름을 공개 소개에도 표시하며, 전역 로고/브랜드·기본 시간표 등 모든 정적 설정 통합은25.3 후속이다.

예배 시간 필드는 기본 시간표 아래의 추가 안내 글이다. 이 저장만으로 정적 시간표 카드가 바뀐다고 안내하지 않는다. 기본 안내/저장값을 구분하며 인사말·주소/전화·방문 설명 등을 편집한다.

## 동작 보존

공통 관리 링크에 각 화면의 기존 미저장 이탈 확인을 연결한다. 주보는 기존 logout 동작을 재사용하고, 교회정보·공지 화면에도 미저장 확인 후 현재 세션 local signOut을 제공한다. 다른 기기 전체 로그아웃으로 바꾸지 않는다. 세션 만료 시 숨긴 입력·같은 계정 재로그인 복구, 다른 계정 전환 보호·자동저장·실패 재시도·복사·게시/취소 조건을 유지한다.

공개 홈페이지/미리보기는 새 탭으로 열어 편집 상태를 보존한다. 인쇄 미리보기는 기존 portal·전용 CSS/4면 배치 규칙을 유지하며 이번 작업에서 인쇄 지면을 재설계하지 않는다.

## 남은 기능과 다음 순서

이번은 관리자 공통 UI다. 현재 편집할 수 있는 기능은 기존 주보·공지·일정·교회정보·주보 이미지다. 모든 홈페이지 문구/사진·계좌/시간표/지도 좌표가 관리자 설정에 통합된 것은 아니다.

다음은25.2 예배 영상 관리: 관리자 예배 종류·예배 날짜·YouTube 링크/영상 선택·제목·대표/공개·제외, 공개 큰 대표 영상+가로 선택 목록. 영상 종류 자동 분류를 필수 전제로 두지 않는다. 이후25.3 홈페이지 설정: 홈 제목2줄/사진·초점/설명·공개 페이지 정보 통합과PC/모바일 미리보기다. 아직 없는 기능을 완성된 관리 메뉴처럼 노출하지 않는다.

별도 진행: 실제 사진/약도, 정식 개인정보/사진 정책·담당/보존·위탁 검토, 인쇄 디테일. 운영 DB/Auth/키/스키마/게시·Production 배포/main 병합은 이번 UI 작업에 포함하지 않는다. 사용자 기존 이슈 자동화 파일은 제외한다.
