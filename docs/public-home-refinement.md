# 공개 홈페이지 세부 개선 · 2026-11-13

최신 추가 피드백 반영은 아래 ‘추가 피드백 반영’ 절을 따른다. 앞선 썸네일 중간 화면·별도 주보 말씀 카드·주소 검색 확대 방식은 사용자 검토 후 대체했다.

## 반영한 피드백

- 홈 첫 화면의 디자인은 유지한다. 환영 문구 아래 줄은 넓은 화면에서도 최소 64px(중간/모바일은 40/24px) 좌우 여백을 확보한다. 2560/1920/1440/1024/768/390/320px 검수.
- 교회 소개·예배·소식의 상위 이름은 각각 인사말·주일예배·교회 소식으로 이동하는 링크다. PC 하위 메뉴는 작은 세로 패널과 짧은 페이드/이동, 화살표 제거. 키보드 포커스로 열고 Escape로 닫으며 숨은 항목은 inert로 탐색에서 제외한다.
- 푸터는 로고/YouTube, 주요 링크5개(교회 소개·온라인 헌금·예배·소식·앱 추가), 주소/연락처의3영역이다. 배너와 중복 문구는 제거한다. 해당 문구는 공식 주보/목사님 인용이 아니라 이전 구현 때 작성한 제안 문구였다. 로그인·맨 위로·저작권만 구분선 아래 둔다.
- 설치/오프라인 기능은 /install로 옮긴다. 홈에서 발생한 설치 가능 이벤트를 브라우저 메모리에 보관해 페이지 이동 후에도 설치 버튼을 사용할 수 있다. 영구 저장/자동 설치는 하지 않는다.
- 소개/예배/소식 상단은 여백을 줄이고 은은한 배경 장식을 넣는다. 실제 사진으로 가장하지 않는다. 주보·공지·일정은 공통 제목/소식 메뉴, 따뜻한 카드/빈 상태로 정돈한다. 주보 본문 목차는 고정 헤더 아래에 머문다.
- 사용자 확인 정보: 주일오후예배는 첫째·셋째 주일 오후1시. 농협 일반헌금301-0223-0182-71 / 건축헌금301-0220-0484-81, 예금주 모두 좋은교회. 확인된 계좌만 표시한다.
- 지도는 주소 검색+zoom17로 요청하며 주변을 가까이 보도록 한다. 실제 지오코딩/표시 위치는 Google 제공 결과에 의존하므로 최종 지도/도보 경로를 확인해야 한다. 관리자 ‘오시는 길’ 본문이 공개되면 경로 안내로 함께 표시한다. 확인되지 않은 역/정류장·도보 시간은 만들지 않는다.
- 인사말은 기존 관리자 교회 정보의 공개 introduction 본문과 연결되어 있다. 편집 화면에 용도를 설명했다. 홈페이지의 첫 제목/사진까지 편집하는 CMS는 아직 없다.
- 토라&토브(/torah-tov)는 최신 공개 주보의 토라/토브/묵상 가이드/암송 제목 항목을 읽는다. 주일예배는 최신 공개 주보의 설교 블록·예배 말씀/공지 제목을 읽는다. 공개 날짜/원본 링크를 표시하며 해당 주에 항목이 없으면 빈 안내다. 별도 원문 복제/자동 게시 없음. 일반 text 제목 규칙에 따른 연결이므로 확정 콘텐츠 유형은 후속 작업이다.
- 새 /api/bulletin-sections는 세션/서비스 키를 상속하지 않는 익명 RLS 클라이언트로 published 부모와 웹 공개 항목만 조회한다. no-store,15초 재조회/포커스 재조회, 실패 시 기존 본문 제거/재시도. 운영 초안을 게시하지 않는다.
- 재생 전에는 최대 해상도 썸네일을 요청하고 없으면 일반 표지로 대체한다. 클릭 후 YouTube nocookie iframe을 연다. YouTube 자체 미리보기/원본 썸네일이 저화질이면 고화질을 만들어낼 수 없고, 재생 화질은 플랫폼·회선·기기에 따라 정해진다. 다른 예배의 현재 재생목록은 등록 순서임을 명시한다.

## 문구·사진 관리 방식 제안

레이아웃/폰트/반응형은 코드, 운영자가 바꾸는 제목·설명·사진·인사말은 관리자 입력으로 관리하는 편이 적합하다. 관리자 홈페이지 설정을 별도 작업으로 만든다. 인사말은 기존 기능을 그대로 사용한다.

- 제목을 첫 줄/둘째 줄로 분리해 각 줄에 권장 길이와 최대 길이를 둔다. 최종 제한은 실제 서체의 렌더링/320px와PC 미리보기로 정하며 글자 수만으로 줄바꿈을 보장하지 않는다. HTML/임의 CSS 입력은 받지 않는다.
- 설명과 버튼 문구도 별도 필드로, PC/모바일 미리보기와 저장/공개 흐름을 제공한다. 잘리는 말줄임으로 중요한 문구를 숨기지 않는다.
- 사진은 ‘투명 일러스트(contain)’와 ‘일반 사진(cover, 초점 위치)’을 구분한다. 누끼 필수 제한은 하지 않는다. 종횡비·최소 해상도·파일 용량·대체텍스트·EXIF 제거·저장 실패 처리와 기존 사진 유지가 필요하다.
- 실제 사진 추천: 인사말의 목사님 사진, 소개 상단의 예배당 전경, 웰컴의 예배/교제 장면, 오시는 길의 건물 입구/간판·사용자 제공 약도. 첫 화면의 추상 장식은 현재 유지해도 좋다. 식별 가능한 사람의 공개 근거/의사와 사진 이용 권한을 확인한다.

## 예배 영상 라이브러리 · 다음 기능 작업

현재 공식 공개 재생목록은 과거 영상부터 시작한다. 일부 목록은 최신 업로드 전체를 담지 않거나100개 초기 화면 뒤에 추가 페이지가 있어 단순 역순이나 공개 HTML만으로 전체 최신순을 보장하지 못한다. 실제 제목/순서를 확인했고 이 동작을 ‘모든 예배 최신순 자동 수집 완료’로 기록하지 않는다.

추천: 관리자 등록/보정 + 공식 API 자동 수집. 예배 종류·날짜·제목·YouTube URL/영상ID·대표 영상·공개 여부를 운영자가 정한다. 자동 수집은 후보를 만들고 분류/중복/비공개·삭제 영상을 검사한다. 수동 지정은 자동 결과보다 우선하며 재수집해도 보존한다.

다음 구현 순서: (1) 예배4종 영상 등록·분류·대표 영상/제외·날짜 정렬 모델과 관리자 입력 (2) 큰 대표 영상+하단 가로 스크롤/키보드 선택·이전 영상 더보기 (3) YouTube Data API의 uploads/playlistItems 페이지 순회·주기 캐시·쿼터/실패/중복 처리 (4) 예배 날짜와 공개 주보 말씀 매칭. API 키 발급/서버 등록은 별도 준비가 필요하며 키를 채팅에 받지 않는다.

공식 문서: [playlistItems.list](https://developers.google.com/youtube/data/reference/rest/v3/playlistItems/list)는 nextPageToken을 지원하고 한 요청 최대50개다. [임베드 매개변수](https://developers.google.com/youtube/player_parameters)만으로 임의 분류/전체 최신순을 지정하는 기능은 제공되지 않는다.

## 개인정보·사진 정책 검토 · 공개용 확정문 아님

현재 시행 조문(2026-09-11 시행)을 확인했다. [개인정보 보호법30조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025127663)는 처리방침을 규정한다. [58조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1030189265)의 종교단체 예외는 선교 등 고유 목적의 수집·이용 범위이며 사이트 모든 처리의 포괄 면제라고 단정하지 않는다. 적용 제외에도 최소 처리·안전 관리·고충 처리 조치가 필요하다.

이 사이트의 실제 처리(관리자 이메일/인증, 운영 로그, 공개 주보, Vercel/Supabase/Google Drive 운영·백업, YouTube/지도 등 외부 서비스)를 조사해 처리방침을 준비하는 것을 권한다. 실제 수탁/국외 이전·보존 기간·담당/삭제 요청 창구를 확인하기 전 임의로 ‘법적 준수 완료’ 문구나 정책 시행일을 만들지 않는다.

별도 ‘사진 게시정책’ 페이지가 모든 교회에 일률적으로 필수라고 단정하지 않는다. 다만 공개 가능 범위·당사자 의사/동의·아동 사진의 보호자 확인·촬영/게시 제외 요청·삭제 요청 및 사진 이용 권한 기준은 마련할 것을 권한다. 주보의 항목 공개 토글만으로 촬영/게시 동의가 성립하는 것은 아니다. 실제 정책이 확정되면 푸터 구분선 아래에 작은 링크를 추가한다. 현재 공개용 가짜 정책/빈 링크는 넣지 않았다.

## 범위

이번은 공통 UI/교회 안내/소식 정돈·공개 주보 연결과 썸네일 개선이다. 홈페이지 설정 CMS·예배 전체 영상 라이브러리·API 키·실제 사진/교통 경로·정책 최종 확정·로그인 디자인은 별도 WBS로 남긴다. 운영 DB/스키마/Auth/키/게시·운영 배포는 변경하지 않는다. 기존 사용자 이슈 자동화 파일 수정은 포함하지 않는다.

## 검증

lint·타입 검사·단위29개·별도 경로 프로덕션 빌드 통과. 공개/설치/오프라인/자체 UI 접근성/메뉴·예배/소식 연결·실패 복구·반응형 브라우저16건 통과. 2560~320px 가로 넘침과 환영 문구 여백 확인, 1440/390px 홈과 예배 화면 촬영에서 JS오류 없음. 새 배경의 소제목 대비와 페이지 이동 중 설치 이벤트 보존을 검증 중 발견해 수정했다. 검증 빌드 산출물은 ESLint 제외 경로에도 추가했다.

실행 환경에서는 i.ytimg.com이 네트워크 정책으로 거절되어 실제 고해상도 이미지 표시를 확인하지 못했다. 양쪽 썸네일 요청 실패 시 교회 테마 표지가 나오는 동작과 클릭 후 올바른 YouTube iframe 전환은 검증했다. 실 사용자 회선에서 썸네일 품질 확인은 남는다. 외부 플레이어 내부 접근성·원본 전사 정확도·실물 인쇄·실제 대중교통 경로를 검증한 것으로 기록하지 않는다.

## 추가 피드백 반영

- 별도 표지→플레이어의 두 번 조작을 없애고 바로 YouTube nocookie iframe을 표시한다. 자동재생은 하지 않는다. 영상의 원본 미리보기 화질은 YouTube에 따른다.
- 건물 이름을 선아빌딩으로 정정한다. 과거 공개 교회정보 필드의 ‘선인빌딩’도 표시 시 정정한다. 사용자가 확인한 ‘샘터마을2단지아파트 앞, 행신초등학교 도보2분’을 안내한다. 다른 역·정류장/경로를 추측하지 않는다.
- 지도는 주소 자유검색의 엉뚱한 결과를 확대하지 않도록 건물 중심37.6223746,126.8354385와zoom16을 사용한다. [같은 건물의 사업자 지점 안내](https://www.nassau-nsa.co.kr/bbs/board.php?bo_table=table40)에서 도로명/선아빌딩 일치, [주소·좌표 자료](https://findby.co.kr/details/10518-412813192095-st-652b0e5f8c641f9e388c9113)에서 지번행신동996-4·좌표를 확인했다. 관리자에서 다른 주소를 등록하면 그 주소 검색을 사용한다. 현재 검수환경의 Google 지도 표시가 네트워크 정책으로 막혀 실제 지도 타일·핀은 사용자 회선에서 최종 확인이 필요하다.
- 예배4탭의 ‘함께 예배하는 시간’ 각 카드에 최신 공개 주보의 `새벽예배 말씀: …`, `금요예배 말씀: …`, `주일예배 말씀: …`을 시간 아래 표시한다. ‘예배 묵상 진행’ 일반 글에 들어 있는 명시 라벨도 읽는다. 이전 별도 설교/말씀 카드는 제거하고, 설교 제목을 보고 예배 종류를 추측하지 않는다. 쉼표로 이어진 예배 라벨/개행을 지원하고 성경 본문 안의 쉼표는 보존한다. 날짜/원본 주보 링크·실패 시 이전 말씀 제거/재시도 지원.
- 교회소개의 예배시간 안내는 주간 말씀 API를 호출하지 않는다. 기존4종 외 주일 학생 예배09:30, 매월 첫날 월삭새벽예배05:25를 표시한다.
- 푸터의 위/아래·영역 사이 여백을 줄이고 TOP을 푸터 바깥 위쪽으로 이동한다. 작은 하단 링크는 개인정보처리방침→사진 게시정책→로그인 순서다. TOP은 모션 줄이기를 따르고 인쇄에서는 숨긴다.
- /legal/privacy와/legal/photo는 실제 페이지로 연결한다. 현재는 담당/요청 창구·보존/서비스 처리 기준이 미확정인 ‘정책 확인 중’ 안내 초안이며 noindex다. [LDI](https://www.ldi.kr/)의 푸터 정책 링크 위치를 참고했으며 타 조직의 담당자·기간·동의/시행일을 복제하지 않는다. 우리 사이트의 확인된 처리/기기 저장, 사진 공개/외부 사본 회수 한계, 정책 검토 항목을 적고 교회 연락처로 연결한다. 정식 정책 확정·법적 준수 완료·운영 게시로 기록하지 않는다.

### 다음 구현과 확인할 사항

예배 영상은 재생목록이 미정리이고 제목/설명만으로 종류를 분류하기 어렵다는 사용자 확인에 따라 수동 등록을 기본으로 한다. 관리자 예배 종류·예배 날짜·YouTube 링크/선택·제목·대표/공개를 먼저 구현하고 큰 대표 영상 아래 가로 선택 목록을 연결한다. API 키 없이 링크 입력은 가능하게 한다. YouTube 채널 후보 선택은 썸네일 확인 후 운영자가 확정하는 보조 기능이다. 비전/텍스트 자동 분류와 공식 API 수집은 선택적인 후속이며 완료 필수 조건으로 두지 않는다. 가로 선택 목록은 아직 없다.

사용자 확인 필요: 실제 회선에서 선아빌딩 지도 중심이 맞는지, 정식 정책에 공개할 담당자 표기·문의 연락처. 처리 항목별 보존기간과 외부 서비스 처리/위탁/국외 범위는 추가 조사해 구체안을 제시한다. 기존 백업 담당 지정만으로 개인정보 보호책임자 실명 공개를 승인받았다고 해석하지 않는다.

검증: 단위30개·타입/lint 통과, 브라우저13건(직접 임베드, 시간별 말씀/실패 복구/안내 탭 제외, 추가 예배시간, 정책 링크·TOP·모바일, 기존 설치/공개정보 및 자체 접근성) 통과. Google 지도 타일/외부 YouTube 플레이어의 실제 재생은 자동 접근성 통과 범위에 포함하지 않는다.
