# 교회 정보·주보 이미지 관리

## 사용 흐름

- `/admin/church`: 기존 편집 계정으로 교회 정보 수정·이미지 업로드·삭제.
- `/church`: 공개로 선택한 교회 정보만 표시. 최초 값은 비어 있으며 실제 정보는 관리자 입력 후 반영된다.
- `/admin/bulletins`: 이미지 보관함에서 선택해 주보에 추가. 제목·설명·웹 공개 여부를 주보별로 수정한다.
- 이미지는 공개 기본값, 다음 주 복사 시 재확인 대상으로 추가된다. 인쇄 데이터에는 비공개 이미지도 유지한다. 실제 인쇄 화면은 후속 작업이다.

교회 정보는 교회 이름·주소·연락처·예배 시간·소개·오시는 길을 지원한다. 공개 여부 기본값은 모두 공개다.
관리 화면에서 수동 저장하며 공개 안내에 즉시 반영한다. 공개 화면은 15초 및 탭 복귀 시 갱신한다.
동시 수정은 revision으로 차단하며 실패 시 입력을 보존한다. 같은 계정 재로그인 시 현재 탭의 입력을 유지한다.
교회 정보를 수정해도 기존 주보 내용은 바뀌지 않는다.

## 이미지 정책

- JPEG·PNG·WebP 정지 이미지, 업로드 최대 8MB·원본 최대 4천만 픽셀.
- 서버에서 실제 파일 형식·손상 여부를 검사한다. 확장자·MIME만 신뢰하지 않는다. SVG·애니메이션은 거절한다.
- 회전 정보를 적용하고 긴 변 2400px 이하로 비율을 유지해 조정한다. 작은 이미지는 확대하지 않는다.
- WebP 품질 90으로 변환하고 EXIF 등 부가정보를 제거한다. 원본 파일은 저장하지 않는다.
- 제목 1~200자, 대체텍스트 1~500자 필수. 주보에 넣을 때 대체텍스트를 복사해 주보별 변경·역사 보존이 가능하다.
- 교체는 새 이미지 업로드로 처리한다. 기존 파일 덮어쓰기는 허용하지 않는다.
- 초안·과거 주보에서 사용 중이면 파일 삭제를 거절한다. 주보 항목 삭제만으로 파일이 자동 삭제되지는 않는다.
- 같은 파일이 여러 주보에 쓰이면 하나라도 공개 게시 중일 때 파일이 공개된다. 특정 주보만 비공개로 바꿔도 다른 공개 주보의 이미지는 유지된다.
- 이미 내려받은 파일은 회수할 수 없으므로 게시 전 공개 여부를 확인한다.

## 저장·권한

`church_info`: 고정된 6개 항목. 편집자는 조회·수정만 가능하고 익명 사용자는 공개 행의 key/body만 조회한다.
`save_church_info`는 6개 항목을 한 트랜잭션으로 검증·저장한다. 일반 사용자에게 임의 항목 생성·삭제를 허용하지 않는다.

`bulletin_images`: 이미지 정보. `bulletin_items.image_asset_id`는 image 블록 content의 ID에서 생성되며 외래키로 연결된다.
이 외래키가 동시 주보 저장/이미지 삭제 사이에서도 참조 무결성을 보장한다.
`bulletin-images` 버킷은 비공개다. RLS는 편집자 또는 공개 게시된 항목이 참조하는 이미지의 익명 읽기만 허용한다.
이미지 정보와 파일의 직접 삽입·덮어쓰기·삭제는 클라이언트에 허용하지 않는다.

`POST /api/images`와 `DELETE /api/images?id=UUID`는 Bearer 토큰의 사용자와 church_editors 등록을 검증한 뒤
서버 전용 서비스 키를 제한된 파일 작업에 사용한다. 키는 브라우저로 전달하지 않는다.
업로드는 파일 저장 후 이미지 정보를 등록하며 등록 실패 시 파일 정리를 시도한다.
삭제는 이미지 정보를 먼저 삭제한다. 참조 중이면 거절되며, 파일 삭제 실패 시 같은 ID로 재시도할 수 있다.

`GET /api/images?id=UUID`는 사용자 토큰 또는 익명 권한으로 저장소에서 읽는다. 서비스 키를 사용하지 않는다.
응답은 no-store이며 공유 이미지 최적화 캐시나 만료 전 접근 가능한 서명 URL을 쓰지 않는다.
관리자 미리보기는 인증된 요청 결과의 임시 blob URL을 사용하고 화면 해제 시 폐기한다.

## 환경·검증

서버에는 기존 `SUPABASE_SERVICE_ROLE_KEY`가 필요하다. 로컬 검증 스크립트는 로컬 키를 해당 프로세스에만 주입한다.
운영 `.env.local`은 수정하지 않는다.

- `tests/images.test.mjs`: 실제 형식·크기·리사이즈·메타데이터 제거 검증.
- `tests/church.integration.mjs`: 정보 비공개·충돌, 직접 업로드/덮어쓰기 차단, 이미지 공개/비공개·게시 취소, 과거 주보 참조 보호.
- `tests/e2e/church.spec.ts`: 관리자 입력부터 업로드·주보 삽입·게시·게시 취소·사용 중 삭제 차단·미사용 삭제까지 검증.
- 최근 100개 이미지 목록과 임시 UI를 사용한다. 검색·페이지네이션·최종 디자인은 후속이다.
