# 관리자 입력 화면

주보 편집 상단에 저장 상태·미리보기·저장 버튼을 모았다. 저장됨/변경 있음/저장 중/저장 실패·입력 유지/게시됨·읽기 전용을 구분하며, 실패에는 경고색과 문구를 함께 사용한다. 게시된 주보에는 자동 저장 안내 대신 공개 취소 후 수정 안내를 표시한다.

주보 내용과 게시 전 확인 구역으로 이동하는 링크를 제공한다. 모바일은 주요 버튼과 입력창을 한 열로 배치하고 보관함은 최대 220px 영역 안에서 스크롤한다. 선택창·버튼은 최소 44px, 입력 및 레이블은 16px이며 링크·선택창에도 키보드 포커스를 표시한다. 공유 관리자 스타일이므로 공지·일정·교회 정보 입력에도 기본 입력 규칙이 적용된다.

저장·권한·게시 로직은 기존 구현을 사용한다. 모바일 320/390px 가로 넘침과 버튼 크기 확인, 자동 저장 중 추가 입력/저장 실패/세션 만료 후 복구, 주보 생성·복사·다시 열기 E2E 2건 통과.

## 공지·일정·교회 정보

일정 종료와 게시 기간 종료는 각각 시작보다 늦어야 하며, 잘못 입력하면 저장 요청 전에 한국어 안내를 표시한다. 실패 시 작성 내용은 유지한다. 공지·일정 저장 상태와 교회 정보 변경/처리 상태를 표시하고, 모바일 저장 작업은 한 열로 배치한다.

교회 정보와 이미지 요청은 처리 중 중복 실행을 막는다. 로그아웃 안내를 표시하고 현재 탭의 입력을 유지한다. 선택한 파일명을 상태로 표시해 로그인 후 파일 선택 UI가 다시 표시되어도 보관 중인 파일을 알 수 있게 한다.

검증: 320px 모바일, 일정 시간 검증, 교회 정보 저장 실패 후 입력/공개 설정 유지 및 재시도, 기존 민감 공지 비공개·주보 복사·이미지 변환/삭제 보호 검증을 수행한다. 같은 계정 재로그인 시 미저장 일정/교회 정보를 복원하고 다른 계정은 기존 owner 검사로 초기화한다.

최종 색감과 시각 디자인은 추가 검토한다.
