# 관리자 입력 화면

주보 편집 상단에 저장 상태·미리보기·저장 버튼을 모았다. 저장됨/변경 있음/저장 중/저장 실패·입력 유지/게시됨·읽기 전용을 구분하며, 실패에는 경고색과 문구를 함께 사용한다. 게시된 주보에는 자동 저장 안내 대신 공개 취소 후 수정 안내를 표시한다.

주보 내용과 게시 전 확인 구역으로 이동하는 링크를 제공한다. 모바일은 주요 버튼과 입력창을 한 열로 배치하고 보관함은 최대 220px 영역 안에서 스크롤한다. 선택창·버튼은 최소 44px, 입력 및 레이블은 16px이며 링크·선택창에도 키보드 포커스를 표시한다. 공유 관리자 스타일이므로 공지·일정·교회 정보 입력에도 기본 입력 규칙이 적용된다.

저장·권한·게시 로직은 기존 구현을 사용한다. 모바일 320/390px 가로 넘침과 버튼 크기 확인, 자동 저장 중 추가 입력/저장 실패/세션 만료 후 복구, 주보 생성·복사·다시 열기 E2E 2건 통과.

후속: 공지·일정 및 교회 정보 입력 화면의 개별 검증·오류 복구·모바일 흐름 점검. 최종 색감과 시각 디자인은 추가 검토한다.
